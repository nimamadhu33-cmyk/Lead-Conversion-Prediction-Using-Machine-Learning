Lead Conversion Prediction Using Machine Learning

Project Overview

A machine learning project that predicts marketing lead conversion using historical lead data.

Technologies

- Python, Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn, Google Colab

Models

- Logistic Regression
- Random Forest Classifier

Results

- Logistic Regression: 99.76% accuracy
- Random Forest: 99.59% accuracy

Objective

To predict lead conversion and support data-driven marketing decisions.
